# Konteks Workspace: Teori Kontrol Linear (MA4171)

## Deskripsi Folder
Folder ini adalah workspace perkuliahan untuk mata kuliah **Teori Kontrol Linear (MA4171)**.
Pengguna sedang mengerjakan tugas-tugas perkuliahan (dimulai dari **Tugas 1**).

## Aturan & Preferensi Pengerjaan
1. **Konteks Otomatis**: Pengguna tidak perlu mengulang penjelasan tentang tujuan atau isi folder ini pada prompt-prompt berikutnya.
2. **Pengerjaan Bertahap**: 
   - Pembahasan soal dilakukan secara bertahap nomor demi nomor.
   - **Dilarang** menuliskan pembahasan nomor selanjutnya sebelum diminta secara eksplisit oleh pengguna.
3. **Format & Gaya Penulisan**:
   - Menghasilkan file LaTeX (`.tex`) beserta hasil kompilasi PDF (`.pdf`) di dalam folder tugas terkait (misal: `Tugas 1/`).
   - **Gaya Tugas Mahasiswa**: Jangan menggunakan `\section` atau `\subsection` seperti format paper/jurnal ilmiah. Gunakan format lembar jawaban tugas kuliah yang bersih dan rapi dengan penomoran soal utama (misal: **No. 1**, **(a)**, **(b)**).
   - **Tanpa Penomoran Step**: Di dalam pembahasan/penyelesaian soal, **jangan gunakan penomoran angka untuk setiap langkah (step)** (hindari format 1., 2., 3., dst. pada langkah). Cukup gunakan kalimat pengantar yang singkat dan mengalir untuk menjelaskan langkah berikutnya.
   - Bahasa pembahasan: Bahasa Indonesia formal, runtut, dan mudah dipahami langkah demi langkah.
